# 🎵 Neon Music Player

A modern and responsive music player built with HTML, CSS and JavaScript.

## ✨ Features

- ▶️ Play and pause music
- ⏮️ Previous and next track
- 🎚️ Volume control
- ⏱️ Music progress bar
- 🔄 Automatic next track
- 📱 Responsive design
- 🌌 Modern neon UI with animations

- ## 🌐 Live Demo

[View Live Demo](https://alipc864-del.github.io/neon-music-player/)

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
